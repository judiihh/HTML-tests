# 💗 Pink Website Practice

Welcome to **Judith's Cute Pink Corner** – a playful practice website built to experiment with HTML, CSS, and a sprinkle of JavaScript magic. The heart of the project lives in `HTML-tests/Practice Web/PinkWebsite.html`. 🌸

## ✨ Highlights
- **Soft pink gradients** and sparkly accents that set a cozy, friendly tone.
- **Hero badge** with animated sparkles highlighting what's new and exciting.
- **Feature cards** opening modals for "My Story", "My Why's", and "Playful Vibes" (portfolio projects!).
- **Floating hearts** animation for delightful, interactive clicks. 💕
- **Mini gallery** with polaroid-style placeholders you can personalize.
- **Contact row** featuring quick links to GitHub, LinkedIn, Instagram, and email – perfect for staying connected. 💌

## 🚀 Getting Started
1. Open the repository folder in your editor of choice.
2. Launch the page by opening `HTML-tests/Practice Web/PinkWebsite.html` in your browser (double-click or drag it in).
3. Explore the hero section, open the modal cards, and click around to see the sparkles and floating hearts.

## 🌟 Portfolio Projects (inside "Playful Vibes")
- **VitaPink BloodBank** — a platform that connects blood donors with blood centers.
- **Web Calculator** — a login-protected web app with a basic calculator.
- **Simple Shell** — a custom implementation of a Unix shell.
- **Inventory WJ** — an inventory web app for adding and searching inventory items.
> Tap the "Playful Vibes" card on the page to open the modal and explore these highlights.

## 🔧 Customization Ideas
- Swap the modal stories for your own chapters and motivations.
- Replace the gallery placeholders with photos, quotes, or art.
- Tweak the color variables in the `<style>` block to try new palettes.
- Extend the feature grid with more buttons and modals for future projects.

## 🛠️ Tech Stack
- **HTML5** for semantic structure.
- **CSS3** for responsive, polished visuals (including custom animations and gradients).
- **Vanilla JavaScript** powering modals, sparkle toggles, and floating hearts.

Enjoy crafting your own pink-perfect web moments! 🌷
